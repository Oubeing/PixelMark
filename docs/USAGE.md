# PixelMark 使用手册

本手册面向使用者，详细介绍每一项功能的操作方法与行为细节。
快速上手请先阅读根目录的 [README](../README.md)。

---

## 1. 画布与文件

### 新建画布

`文件 → 新建`（Ctrl+N）。对话框可设置：

- **宽 / 高**：16–10000 像素，默认取当前画布尺寸；
- **背景**：白色，或当前背景色。

新建会清空当前画布与测量标注（可用撤销恢复）。

### 打开图像

`文件 → 打开图像`（Ctrl+O）。支持 PNG / JPG / JPEG / BMP / GIF / WebP。

- 打开成功后**自动适应窗口**，整图完整可见（见第 6 节视图缩放）；
- 打开成功后，"还原"（编辑 → 还原）将回到刚打开的状态；
- 文件损坏或格式不支持时会弹出错误提示，不会崩溃；
- 打开新图像会清空此前的测量标注（测量属于特定图像）。

### 其他获取图像的方式

- `工具栏 → 摄像头拍照` 或 `获取 → 摄像头拍照`：实时预览后拍照载入画布（见第 7 节）；
- `工具栏 → 视频截帧` 或 `获取 → 视频截帧`：从视频文件中截取画面载入画布（见第 7 节）。

### 保存

| 菜单项 | 行为 |
|---|---|
| 保存（Ctrl+S） | 保存到当前路径；**包含**测量标注（成品图） |
| 另存为 | 询问路径，包含标注 |
| 保存为不含标注 | 询问路径，仅原始画布 |

保存失败（如路径只读、格式不支持）会弹错并记录日志，不会静默丢失。
关闭窗口时若有未保存修改，会提示保存 / 不保存 / 取消。

## 2. 绘图

### 工具与按键

画笔 `B`｜喷桶 `U`｜直线 `L`｜矩形 `R`｜椭圆 `O`｜橡皮擦 `E`｜
箭头 `A`｜文字 `T`｜取色 `I`

### 鼠标约定

- **左键**：以前景色绘制；
- **右键**：以背景色绘制（画笔/直线/矩形/椭圆/箭头/橡皮擦均适用，沿用既有交互）；
- **拖拽**：直线/矩形/椭圆/箭头需要拖出起终点；画笔/橡皮擦为自由绘制；
- **右键**：随时取消进行中的多点操作（如测角）。

### 画笔属性面板

左侧「工具选项」区固定在工具网格下方、**始终可见**（无折叠分组）：选画笔时显示
粗细/颜色/平滑，选矩形时显示填充/虚线，选测量工具时显示该工具的使用提示。可调项：

| 属性 | 说明 | 出现的工具 |
|---|---|---|
| 粗细 | 1–200 px，下拉选择或直接输入（自动纠正非法值） | 画笔/橡皮擦/直线/矩形/椭圆/箭头 |
| 前景色 / 背景色 | 点击按钮选择；取消选择保持原色不变 | 全部绘图工具 |
| 填充形状 | 矩形/椭圆是否填充（画笔色） | 矩形/椭圆/箭头 |
| 虚线样式 | 直线/形状使用虚线（橡皮擦除外） | 画笔/直线/矩形/椭圆/箭头 |
| 平滑笔迹 | 自由绘制时做二次贝塞尔平滑 | 画笔/橡皮擦 |
| 不透明度 | 10%–100%，影响所有绘制与填充 | 全部绘图工具 |

### 各工具行为

- **画笔**：按下即开始绘制，拖动连续笔画，抬起结束；每一笔是一个撤销步。
- **喷桶**：单击填充与点击处颜色连通的区域（4 连通）；容差为 0（精确匹配）。
- **直线/矩形/椭圆**：拖拽时显示半透明预览（双缓冲），抬起后提交。
- **橡皮擦**：等同于用背景色绘制。
- **箭头**：拖出起点到终点，箭头头部大小随笔画粗细自适应。
- **文字**：单击画布 → 输入多行文字与字号 → 绘入图像（带半透明底框）。
- **取色**：单击画布把该像素颜色设为前景色（颜色按钮同步更新）。

## 3. 测量标注

> 测量标注是**叠加层**：不修改图像像素，可随时删除；保存时可选择是否合并进成品图。

### 3.1 比例尺标定（一切测量的基础）

1. 选择 `测量标注 → 标定比例尺`（快捷键 `C`）；
2. 在图像上**已知实际长度**的对象上拖出一条线（例如影像中的标尺 10 mm 段）；
3. 在对话框输入实际长度与单位，确定；
4. 界面显示当前比例，如 `1 px = 0.0333 mm`。

标定示例：拖出的线段长 300 px，输入实际长度 `10 mm` → 比例 `30 px/mm`。
此后测距 150 px 会显示 `150.0 px（5.00 mm）`。

清除标定：`测量 → 清除比例标定`，此后测量回到纯像素值。
删除列表中的"标定线"不影响已生效的比例尺。

### 3.2 各测量工具

| 工具（快捷键） | 操作 | 输出 |
|---|---|---|
| 测距（D） | 拖拽两点 | 距离线 + 端点刻度 + 数值标签 |
| 测角（G） | 点击 起点 → 顶点 → 终点 | 两条边 + 圆弧 + 角度值 |
| 测面积（M） | 拖出矩形 | 半透明填充矩形 + 边长与面积 |
| 测圆（V） | 从圆心拖出半径 | 圆 + 半径虚线 + R/D/面积 |
| 比例尺（S） | 单击画布 / 拖拽 | 黑白分段比例尺；单击用"整齐长度"，拖拽自定义长度 |
| 箭头标注（N） | 拖出箭头，松开输入文字 | 箭头 + 文字框（文字可留空） |
| 文字标注（Y） | 单击后输入文字 | 文字框 |

测量过程随时可右键取消；Esc 也可取消进行中的多点操作。
缩放视图不改变测量数值——测量始终按图像像素计算，再按比例尺换算为实际值。

### 3.3 显示单位切换

测量标注面板中的「显示单位」下拉：

- **跟随标定单位**：使用标定时输入的单位（默认）；
- **mm / cm / m / μm / in**：即时换算显示，不改变标定关系。
  例如标定为 `30 px/mm`，切换到 cm 后同样 300 px 会显示 `1 cm`。

### 3.4 测量列表面板

右侧面板列出全部测量（序号 + 类型 + 数值）：

- **单击列表项**：画布上对应测量高亮为蓝色；
- **定位所选**（或双击列表项）：滚动到该标注并居中高亮；
- **删除所选**：删除选中项（或聚焦画布后按 Delete）；
- **清除全部标注**：清空全部测量与标注（可撤销，`Ctrl+Z` 恢复）；
- **导出 CSV**：序号 / 类型 / 点坐标 / 像素值 / 实际值 / 标注文字，
  UTF-8 BOM 编码，Excel 可直接打开；
- 面板可通过 `测量 → 显示/隐藏测量面板` 或标题栏关闭按钮收起。

## 4. 图像处理

### 基础调节（对话框）

`图像 → 图像调节`，或左侧面板「图像处理 → 图像调节」按钮，四个滑块：
亮度 / 对比度 / 饱和度 / 色调（暖色为正、冷色为负）。

- 拖动滑块时画布**实时预览**（不影响正式图像）；
- **确定**：应用调节（进入撤销栈）；
- **取消**：放弃本次调节。

> 调节算法与 Qt 颜色链路逐点一致（含 Qt 颜色量化特性），非正方形图像不再花屏。

### 滤镜（即时应用，均可撤销）

灰度化｜二值化｜反相｜浮雕｜边缘检测（Canny）｜模糊（高斯）｜锐化

入口：左侧面板「图像处理」分区按钮，或 `图像 →` 菜单同名项。

### 旋转与翻转

`图像 → 旋转`：顺时针 / 逆时针（90°）；垂直 / 水平翻转。
`图像 → 还原`：回到打开时的图像。
`图像 → 图像信息`：查看尺寸、格式、测量数量与比例尺。

## 5. 错误处理与日志

- 任何未捕获异常都会：写入日志 → 弹出对话框（含堆栈详情）→ 程序继续运行；
- 常见操作（打开/保存/导出/滤镜）均有针对性错误提示；
- 日志位置：项目 `logs/pixelmark_YYYYMMDD_HHMMSS.log`
  （项目目录不可写时自动切换到系统临时目录）；
- 排查问题时请附带最新日志文件。

## 6. 视图缩放

导入图像后画布**自动铺满绘图区**：图像缩放至覆盖整个绘图区、居中裁剪边缘，
画布控件与绘图区等大——**不出现滚动条、不留边缘空白**。之后可自由切换：

| 操作 | 方式 |
|---|---|
| 放大 / 缩小 | 工具栏按钮、`视图` 菜单、`Ctrl+=` / `Ctrl+-`、`Ctrl+滚轮` |
| 适应窗口 | 工具栏按钮、`视图 → 适应窗口`、`Ctrl+0` |
| 铺满绘图区 | 工具栏按钮、`视图 → 铺满绘图区`、`Ctrl+2` |
| 原始大小（100%） | 工具栏按钮、`视图 → 原始大小`、`Ctrl+1` |
| 平移 | 中键拖拽；或使用滚动条 / 滚轮 |

行为细节：

- **铺满绘图区（默认）**：缩放到图像覆盖整个绘图区，被裁剪的边缘不可见，
  但没有滚动条也没有留白；窗口最大化 / 还原 / 缩放时自动重新计算；
- **适应窗口**：整图完整可见（小图不放大），居中显示，四周为**浅灰底并带边框**；
- **手动缩放**（放大 / 缩小 / 原始大小）退出自动模式，图像超出窗口时
  自动出现滚动条，可滚动查看被裁剪/放大的部分；
- 缩放只影响显示，不影响测量数值与保存的图像分辨率；
- 状态栏显示当前缩放比例与视图模式（铺满 / 适应窗口 / 手动）。

> `视图` 菜单还可分别显示/隐藏：测量面板、左侧工具面板、工具栏、状态栏。

## 7. 获取图像（摄像头 / 视频）

### 7.1 摄像头拍照

`获取 → 摄像头拍照`（工具栏相机图标）：

1. 对话框自动枚举可用摄像头（0–4），下拉可切换设备；
2. 实时预览约 30 fps；
3. 点击 **拍照并载入画布**：当前画面进入画布（可撤销），随后可直接标注测量；
4. 取消则不做任何改变。

> 未检测到摄像头或未安装 OpenCV 时给出明确提示，不影响其他功能。

### 7.2 从视频获取照片

`获取 → 视频截帧`（工具栏胶片图标）：

1. 选择视频文件（MP4 / AVI / MOV / MKV / WMV / FLV / WebP）；
2. 使用 **播放 / 暂停**、**上一帧 / 下一帧** 或拖动进度条定位到目标画面；
3. **截取当前帧并载入画布**，或 **保存当前帧为图片**；
4. 文件无法打开时弹出错误提示。

## 8. 键盘快捷键速查

```
文件     Ctrl+N 新建   Ctrl+O 打开   Ctrl+S 保存   Ctrl+Q 退出
编辑     Ctrl+Z 撤销   Ctrl+Shift+Z / Ctrl+Y 重做
视图     Ctrl+= 放大   Ctrl+- 缩小   Ctrl+0 适应窗口   Ctrl+2 铺满绘图区   Ctrl+1 原始大小
其他     Delete 删除所选测量   Esc 取消当前操作   F1 帮助
工具     B 画笔  U 喷桶  L 直线  R 矩形  O 椭圆  E 橡皮擦
         A 箭头  T 文字  I 取色
         C 标定  D 测距  G 测角  M 面积  V 测圆
         S 比例尺 N 箭头标注 Y 文字标注
```

> 工具快捷键与「绘制 / 测量」菜单、工具栏的勾选状态联动；
> 菜单栏（文件 / 编辑 / 绘制 / 图像 / 获取 / 视图 / 测量 / 帮助）
> 提供了全部功能的入口。
